# Color Sort Puzzle — Development Epics

## 1. Visible Core Puzzle

Deliver the playable visible truck-and-conveyor puzzle: terminal results and readable occupancy.

## 2. Practice and Tier 1

Deliver separate practice levels and five linear, tight-capacity Tier 1 levels.

## 3. Performance Stars and Gates

Deliver per-level occupancy, time, and tap stars; retain the best single run and use the provisional 2.5-star gate.

## 4. Tier 2 Hidden Blocks

Deliver five levels that conceal individual blocks while keeping outcomes understandable. Every level receives automated solver verification and human playtesting before it is added.

## 5. Tier 3 Color-Gated Reveals

Deliver five levels combining hidden blocks with trucks revealed by completing a specified color.

## 6. Cross-Platform Readiness

Release equivalent play on Android, iOS, macOS, Windows, and itch.io web.

## 7. Clear Presentation and Fair Support

Improve visual/audio feedback and, if included, add a non-disruptive optional tip button with no gameplay benefit.

## Deferred — Tier 4

Do not design or build Tier 4 until its mechanic is agreed.
